# First-run media assets

The build phase compiles the CPU/memory and artwork workers for the selected architectures and puts them in `Contents/Helpers`. Scripts and generic icons go in `Contents/Resources/ManagedMedia/v1`. `AppDelegate` invokes `ManagedMediaInstaller` before the first preset is loaded. The installer creates `~/Library/Application Support/MTMR/ManagedMedia/v1` only if absent; it does not overwrite an existing version or an existing `items.json`. On every launch it updates the managed owner-bundle-id used to stop the artwork worker when the owning app exits. Do not run two differently identified builds against the same support directory at once.

A clean install gets a bundled preset with Spotify artwork and playback, CPU/memory graph, flexible Dock, and local level control. An existing preset is left untouched. The graph starts at CPU, and its first sampling pass creates the graph images. The playback widget does not start Spotify by itself. The preset contains no personal playlists, API keys, or account-specific identifiers. The weather widget is present in the default preset without an API key. It displays a setup prompt and does not request location or contact the weather service until the user supplies their own OpenWeather key in their preset. The previous/next buttons address Spotify directly (only while it is already running) rather than sending system media keys. Spotify control can require macOS Automation permission. Artwork retrieval requires network access; the helper accepts Spotify track URIs and falls back to a placeholder for unsupported content or download failure.

The `v1` directory is immutable across launches except for state (`mode.txt`, `history.json`, graph images, artwork, lock and owner marker). When shipping changed managed scripts or helper binaries, bump the version in the installer, all script paths, and the default preset together. Avoid replacing runtime state and user presets during updates. A missing or partial managed installation is reported to the log; automatic repair is intentionally not performed to avoid overwriting files. The current call logs provisioning errors and leaves normal app startup intact.

The standalone test can be built from `MTMR/ManagedMediaInstaller.swift` and `ManagedMediaTests/main.swift`; it installs from the built app bundle into a temporary directory, confirms initial graph generation, and checks that an existing preset and mutable data survive repeated setup. Test the signed, notarized app on a clean Mac as well: hardened runtime, helper signatures, app quarantine, Touch Bar layout and permissions have not yet been verified.
